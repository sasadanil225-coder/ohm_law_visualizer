# Визуализация закона Ома

Интерактивное приложение на Python для наглядного изучения закона Ома через анимацию и визуализацию.

## 📋 О проекте

Проект разработан для школьного индивидуального проекта по физике и информатике. Приложение позволяет:
- Интерактивно изменять параметры электрической цепи (напряжение и сопротивление)
- Наблюдать анимацию движения электронов в реальном времени
- Строить графики зависимости силы тока от напряжения
- Исследовать закон Ома в интерактивном режиме

## 🎯 Цели проекта

1. Создать наглядный инструмент для изучения закона Ома
2. Продемонстрировать возможности программирования в образовании
3. Разработать приложение без зависимостей от внешних библиотек
4. Интегрировать знания физики и информатики

## ✨ Особенности

- **Полностью на Python** — не требует установки дополнительных библиотек
- **Интерактивный интерфейс** — ползунки для управления параметрами
- **Анимация электронов** — скорость соответствует силе тока
- **Динамические графики** — обновление в реальном времени
- **Примеры цепей** — готовые конфигурации для изучения
- **Расчёт мощности** — дополнительные параметры цепи
